# ИИ Ревизор & ИИ Рапорт — Личный Кабинет (Cabinet)

Данный каталог содержит разделенную на модули структуру страниц личного кабинета пользователя. Каждая страница отвечает за свой набор вкладок и функций, сохраняя общую бизнес-логику и синхронизацию состояния с сервером и `localStorage`.

## 🔗 Браузерный роутинг (Browser Routing)

Маршрутизация осуществляется через синхронизацию URL браузера в `App.tsx` и `CabinetPage.tsx`:
1. При клике на любую вкладку меню срабатывает переход `onNavigate('/cabinet/' + tabId)`.
2. При загрузке страницы URL автоматически парсится, извлекая `tabId`, и устанавливает соответствующую активную страницу в кабинете.
3. Это позволяет пользователям сохранять ссылки на конкретные разделы кабинета (например, `/cabinet/revisor_kanban` или `/cabinet/fill_report`) и возвращаться на них при перезагрузке страницы.
